# SponsorFit Report Template

Use this order. Keep the report skimmable and specific.

1. **Project Snapshot** — what it does, users, value, maturity, readiness
2. **What This Project Really Sells** — 3–7 purchased outcomes
3. **Ideal Customer Ranking** — evidence, score, budget, required features
4. **Your Happiest Sponsors** — first-person simulations and one winner
5. **Best Monetization Model** — one primary model and rationale
6. **What Stays Free / What Gets Paid / Never Paywall**
7. **Pricing Hypothesis** — range, unit, and validation method
8. **How to Make the First $1,000** — target, channel, offer, price, message, test
9. **Revenue Ladder** — first $100, $1,000, and $10,000
10. **Top Things to Build Next** — at least five across Revenue, Adoption, Trust, Enterprise, Community
11. **Risks and Unknowns** — demand, license, community, capacity, competition
12. **7-Day Action Plan** — one observable action per day

End with:

```text
YOUR BEST CUSTOMER:
...

THEY PAY FOR:
...

BEST BUSINESS MODEL:
...

BUILD THIS NEXT:
...

FIRST REVENUE MOVE:
...
```

## Evidence language

- Prefix direct facts with **Observed** and cite repository paths or GitHub surfaces.
- Prefix reasoned conclusions with **Inferred** and show the facts used.
- Prefix buyer, demand, price, and channel claims with **Hypothesis** until externally validated.
- Prefer “No evidence found” over filling a blank with a generic claim.
